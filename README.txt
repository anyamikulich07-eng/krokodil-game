КРОКОДИЛ — Firebase prototype

1. В Firebase Console → Realtime Database → Rules вставьте содержимое database.rules.json и нажмите Publish.
2. Проверьте, что Authentication → Sign-in method → Anonymous включён.
3. На GitHub создайте отдельную ветку, например firebase-test, или отдельный репозиторий.
4. Замените index.html файлом из этого архива. Опубликуйте GitHub Pages.
5. Проверьте: сначала с VPN, затем из рабочей сети без VPN. Откройте игру на двух устройствах, создайте комнату и войдите по приглашению.

ВАЖНО:
- Это первая тестовая Firebase-версия, а не точная копия всех деталей исходного интерфейса.
- Комната и чат читаемы любым анонимно авторизованным пользователем, знающим код комнаты. Код комнаты случайный, но это не полноценная система приватности.
- Секретное слово вынесено отдельно и правила разрешают читать его только текущему ведущему.
- Хост должен оставаться онлайн: он проверяет правильные ответы и начисляет очки.
- Пока не заменяйте старую опубликованную игру. Сначала протестируйте отдельную ветку/копию.
